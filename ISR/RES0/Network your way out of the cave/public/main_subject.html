Environnement GNS3
Objectifs

Dans ce quest vous allez découvrir les bases du réseau au travers de l'émulateur GNS3.
Vous devez instancier votre propre VM GNS3 via le one-click deployment C2WK-GNS3 disponible dans ETNA Cloud. C'est sur cette VM que vous devrez effectuer vos étapes, et c'est sur celle-ci que vous serez évalué.

Vous devrez pour chaque étape crée un nouveau projet pour réaliser l'infrastructure demandé.

Tous les équipements nécessaire à la réalisation des étapes sont déja présente sur les VMs pas besoin d'en installer des supplémentaire.

Setup
Pas besoin d'installer le server GNS3

Instanciez votre VM C2WK-GNS3 depuis ETNA Cloud via le one-click deployment. Cette VM embarque un serveur GNS3 v2.2.49 accessible sur le port 80 — pas besoin d'installation locale d'un serveur GNS3.

Installation du client graphique

Cependant vous devez installer un client graphique pour vous connecter a la VM qui vous est fournis

https://github.com/GNS3/gns3-gui/releases/tag/v2.2.49

Suivez les instructions d'installations spécifique a votre plateforme en vous assurant d'installer uniquement les morceau requis pour le client graphique. Faites vous aider de vos assets pour cette étape.

Connexion a la VM

Dans Edit > preferences > Server:

  • Décocher la case d'activation du server local si ce n'est pas déja le cas
  • Dans Remote main server
     - Protocol : HTTP
     - Host : l'address ip de votre VM
     - Port : 80 TCP
     - Auth : [X]
     - User : gns3
     - Password : gns3

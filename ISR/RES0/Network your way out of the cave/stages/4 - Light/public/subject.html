Objectifs

connecter une machine à internet

Equipement nécesaire
  • 1 VPC
  • 1 router c3725
  • 1 NAT
Consignes

Configurer R1 :

  • il doit récuperer une address ip en DHCP pour son interfacce connecter au NAT
  • il doit router les paquets du sous-réseau 192.168.1.0/24 internet
  • son interface dans le sous-réseau 192.168.0.0/20 ait l'addresse ip : 192.168.1.254

Configurer PC1:

  • doit se trouver dans le sous-réseau 192.168.0.0/20
  • doit avoir comme addresse ip : 192.168.1.10
Evaluation
  • R1 doit pouvoir ping internet sur 8.8.8.8
  • PC1 doit pouvoir ping internet sur 8.8.8.8
Indices

Il est possible que votre router mette du temps a recuperer une addresse ip du server DHCP du NAT, ne vous inquietez pas si ca prend quelques dizaines de secondes.

Par défaut le router n'autorise aucun traffic pour rentrer ou sortir du réseau
vous devez donc configurer le router pour autoriser le traffic entrant et sortant.

ajouter ces instructions à la configuration de votre router (en considerant fa0/0 comme interface connecter au NAT):

R1(config)#access-list 10 permit any
R1(config)#ip nat source list 10 int fa0/0 overload

Pas la peine de trop vous attarder dessus, vous aurez pleinement l'occasion de découvrir et manipuler les listes d'accès dans les étapes suivantes.

Attention

Veillez à correctement configurer le router aussi bien via le terminal que l'equipement lui-même.

Rendu

Déposez un screenshot de votre topologie GNS3 montrant le résultat du ping de PC1 vers internet (8.8.8.8) dans le dossier 4 - light/ de votre dépôt git avant de faire votre demande de validation sur l'intranet.

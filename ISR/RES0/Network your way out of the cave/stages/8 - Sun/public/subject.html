Objectifs

Configurer un server DHCP et recuperer des adresses ip dynamiquement.

Equipement nécesaire
  • 2 VPC
  • 1 router c3725
  • 1 switch
Consignes

Configurer R1 :

  • son interface dans le sous-réseau 192.168.1.0/24 ait l'addresse ip : 192.168.1.254
  • un server DHCP qui :
     - distribue des ip dans la range 192.168.1.10 - 192.168.1.50 pour le sous-réseau 192.168.1.0/24

Configurer PC1:

  • doit se trouver dans le sous-réseau 192.168.1.0/24
  • doit recuperer son adresse ip en DHCP

Configurer PC2:

  • doit se trouver dans le sous-réseau 192.168.1.0/24
  • doit recuperer son adress ip en DHCP
Evaluation
  • PC1 et PC2 doivent pouvoir se ping mutuellement
Rendu

Déposez un screenshot de votre topologie GNS3 montrant l'adresse ip obtenue en DHCP par PC1 et PC2 ainsi que le résultat du ping entre eux dans le dossier 8 - sun/ de votre dépôt git avant de faire votre demande de validation sur l'intranet.

Attention

Pensez à bien sauvegarder vos configurations.

Objectifs

Vous devez connecter et faire communiquer 2 machines dans 3 sous-réseaux différent
Pour cela vous allez configurer 2 router c3725 a l'aide du protocol OSPF

Equipement nécesaire
  • 2 VPCs
  • 2 router c3725
Consignes

Configurer R1 :

  • il doit router les paquets du sous-réseau 192.168.1.0/24 vers 10.0.0.0/24 et inversement
  • son interface dans le sous-reseau 192.168.1.0/24 ait l'adresse ip : 192.168.1.254
  • son interface dans le sous-reseau 10.0.0.0/24 ait l'adresse ip : 10.0.0.1

Configurer R2 :

  • il doit router les paquets du sous-réseau 172.16.1.0/24 vers 10.0.0.0/24 et inversement
  • son interface dans le sous-reseau 172.16.1.0/24 ait l'adresse ip : 172.16.1.254
  • son interface dans le sous-reseau 10.0.0.0/24 ait l'adresse ip : 10.0.0.2

Configurer PC1:

  • doit se trouver dans le sous-reseau 192.168.1.0/24
  • doit avoir comme addresse ip : 192.168.1.10

Configurer PC2:

  • doit se trouver dans le sous-reseau 172.16.1.0/24
  • doit avoir comme addresse ip : 172.16.1.10
Evaluation
  • R1 doit pouvoir ping R2 sur son interface dans le sous-réseau 10.0.0.0/24 et inversement
  • PC1 doit pouvoir ping PC2 et inversement
Indices

OSFP est un protocole servant à déterminer le meilleur chemin que peuvent emprunter des paquets pour transiter par une série de réseaux connectés. Il existe d'autre protocole similaire mais c'est celui-ci que vous utiliserez pour vos étapes.
Pas besoin de comprendre parfaitement ce protocole, familiarisez vous simplement avec les quelques commandes de configurations requise ce sera amplement suffisant pour cet introduction.

Vocabulaire important:

  • interface
  • gateway
  • masque de sous-reseau
  • masque inverse (wildcard mask)
  • loopback

Commandes router c3725:

  • config terminal
  • interface
  • ip address
  • router ospf 1
  • network
  • show ip interface brief
  • show ip route
  • show ip protocols
  • show ip ospf neighbor

N'oubliez pas de configurer l'interface loopback de vos router

Rendu

Déposez un screenshot de votre topologie GNS3 montrant le résultat du ping de PC1 vers PC2 dans le dossier 2 - partition/ de votre dépôt git avant de faire votre demande de validation sur l'intranet.

Sauvegarder votre configuration

Lorsque vos router démarrent, leur configuration revient à celle par défaut
Pour sauvegarder votre travail et pouvoir le présenter pour evaluation, n'oublier pas d'effectuer la commande copy running-config startup-config pour garder vos configurations au démarage

Objectifs

connecter un réseau, composé de plusieurs sous-réseaux à internet

Equipement nécesaire
  • 4 VPC
  • 3 router c3725
  • 3 switch
  • 1 NAT
Consignes

Configurer R1 :

  • il doit récuperer une address ip en DHCP pour son interfacce connecter au NAT
  • il doit router les paquets du sous-réseau 192.168.1.0/24 a internet
  • il doit router les paquets du sous-réseau 172.16.0.0/16 a internet
  • il doit router les paquets du sous-réseau 10.0.0.0/24 a internet
  • son interface dans le sous-réseau 10.0.0.0/24 ait l'addresse ip : 10.0.0.254

Configurer R2 :

  • il doit router les paquets du sous-réseau 192.168.1.0/24 vers 10.0.0.0/24 et inversement
  • son interface dans le sous-reseau 192.168.1.0/24 ait l'adresse ip : 192.168.1.254
  • son interface dans le sous-reseau 10.0.0.0/24 ait l'adresse ip : 10.0.0.2

Configurer R3 :

  • il doit router les paquets du sous-réseau 172.16.0.0/16 vers 10.0.0.0/24 et inversement
  • son interface dans le sous-reseau 172.16.0.0/16 ait l'adresse ip : 172.16.255.254
  • son interface dans le sous-reseau 10.0.0.0/24 ait l'adresse ip : 10.0.0.3

Configurer PC1:

  • doit se trouver dans le sous-réseau 192.168.1.0/24
  • doit avoir comme addresse ip : 192.168.1.11

Configurer PC2:

  • doit se trouver dans le sous-réseau 192.168.1.0/24
  • doit avoir comme addresse ip : 192.168.1.12

Configurer PC3:

  • doit se trouver dans le sous-réseau 171.16.0.0/16
  • doit avoir comme addresse ip : 172.16.1.13

Configurer PC4:

  • doit se trouver dans le sous-réseau 172.16.0.0/16
  • doit avoir comme addresse ip : 172.16.1.14
Evaluation
  • R1, R2, R3 doivent pouvoir ping internet sur 8.8.8.8
  • PC1, PC2, PC3, PC4 doivent pouvoir ping internet sur 8.8.8.8
  • PC1, PC2, PC3, PC4 doivent pouvoir se ping mutuellement
Indices

Par défaut le router n'autorise aucun traffic pour rentrer ou sortir du réseau
vous devez donc configurer le router pour autoriser le traffic entrant et sortant.

ajouter ces instructions a la configuration de votre router (en considerant fa0/0 comme interface connecter au NAT):

R1(config)#access-list 10 permit any
R1(config)#ip nat source list 10 int fa0/0 overload

Pas la peine de trop vous attarder dessus, vous aurez pleinement l'occasion de découvrir et manipuler les listes d'accès dans les étapes suivantes.

Rendu

Déposez un screenshot de votre topologie GNS3 montrant les résultats des pings de PC1 vers 8.8.8.8 et de PC1 vers PC4 dans le dossier 5 - delusion/ de votre dépôt git avant de faire votre demande de validation sur l'intranet.
